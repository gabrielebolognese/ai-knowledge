The **Quick, Draw! dataset** is a collection of about 50 million doodles in 345 categories, drawn by players of an online game in which a neural network tries to guess what you draw.<Cite id="quickdraw-repo" /> Google released it openly under a Creative Commons licence, which makes it one of the few large image datasets you may freely copy, adapt and even redistribute.<Cite id="quickdraw-data" /> In this lesson you download a small, balanced slice of it and turn it into tensors for training.

## Where the doodles come from

*Quick, Draw!* is a browser game released by Google in November 2016. A player gets a word such as "umbrella" and has 20 seconds to draw it while the computer guesses.<Cite id="wiki-quickdraw" /> Every drawing was saved as a list of pen strokes, together with the word, the player's country and whether the game recognised it.<Cite id="quickdraw-repo" />

David Ha and Douglas Eck introduced the data to research in 2017 in their *sketch-rnn* paper, a recurrent network that learns to draw. Their version used 75 classes, each with 70,000 training, 2,500 validation and 2,500 test sketches, and they made it public "to encourage further development" of models for vector drawings.<Cite id="ha2017" />

<Analogy breaks="A real party game has a human guesser; here the guesser is your CNN, and it only ever sees the finished, shrunken picture, not the drawing as it happens.">
The dataset is like the stack of paper left over after millions of rounds of a party drawing game: quick, rough sketches, each labelled with the word the player had to draw.
</Analogy>

### Formats, and the one this project uses

The repository offers the same drawings in several formats: raw strokes with timing, simplified strokes, a binary version, sketch-rnn files and **NumPy bitmaps**. The bitmaps are 28×28 grayscale images, rendered from the simplified strokes and centred on each drawing's bounding box.<Cite id="quickdraw-repo" /> That is the same size as <Term slug="mnist">MNIST</Term>, so the CNN from the digits project fits without changes.

## The licence and the content warning

The data is released under the **Creative Commons Attribution 4.0** licence.<Cite id="quickdraw-repo" /> You may share and adapt it for any purpose, including commercial ones, as long as you give appropriate credit, link to the licence and indicate changes.<Cite id="cc-by-4" /> This course credits it as "Quick, Draw! dataset by Google, CC BY 4.0" in the code, the README, the figures and the drawing app.

The repository also warns that the drawings were individually moderated but may still contain inappropriate content.<Cite id="quickdraw-repo" /> In 12,000 drawings per class you are likely to meet a few that are rude, off-topic or simply unrecognisable.

## Downloading only what you need

Each class file in the official bucket holds every drawing of that class: `apple.npy` has 144,722 of them and weighs about 113 MB. The project needs only 12,000 per class. Instead of downloading 1-1.5 GB, `download.py` asks the server for the first bytes of each file only, with an **HTTP Range request**: the client sends a `Range` header, and a server that supports it answers with status 206 Partial Content and just those bytes.<Cite id="mdn-range" />

This works because a `.npy` file is simple. It starts with the magic string `\x93NUMPY`, two version bytes and the length of a text header; the header is a Python dictionary with three keys, `descr` (the data type), `fortran_order` and `shape`. The raw array follows straight after.<Cite id="npy-format" /> For these files the header says `'|u1'` (one unsigned byte per value) and a shape such as `(144722, 784)`, so drawing $i$ occupies bytes $128 + 784i$ to $128 + 784(i+1) - 1$.

The script reads the header with one small request, checks that the data type and row length are what it expects, then fetches exactly $N \times 784$ bytes and saves them as an ordinary `.npy` file of shape `(N, 28, 28)`. It also writes an `ATTRIBUTION.txt` next to the data.

## From files to a balanced split

`data.py` turns the ten files into PyTorch tensors. It opens each file with `np.load(..., mmap_mode="r")`, which memory-maps the file: the array stays on disk and only the rows you index are read into memory.<Cite id="np-load" /> That matters little for 9.4 MB, but the same code works unchanged on a full 270 MB file.

<CodeFile path="code/projects/project-doodles/data.py" lines="49-62" highlight="50,52,54,60" title="data.py: shuffle within each class, then cut" />

Each class is shuffled with a fixed seed and cut into three parts:

| Split | Per class | Total (10 classes) | Used for |
|---|---|---|---|
| Train | 9,000 | 90,000 | updating the weights |
| Validation | 1,000 | 10,000 | choosing settings and watching overfitting |
| Test | 2,000 | 20,000 | one final measurement |

Pixels are divided by 255, so they lie between 0 and 1, and a channel dimension is added, giving tensors of shape `(N, 1, 28, 28)`. Because every class has the same number of drawings, a model that always guesses one class gets exactly 10%, which is the chance level to beat.

<Callout type="note">
The bitmaps are centred on the drawing's **bounding box**, not on its centre of mass as in MNIST, and they fill most of the frame: `python data.py` measures a median longest side of 26 of the 28 pixels. The drawing app must reproduce this framing; the capstone lesson shows how.
</Callout>

## Try it

From `code/projects/project-doodles/`:

```bash
python download.py --smoke   # 2 classes x 500 doodles, under 1 MB
python download.py           # 10 classes x 12,000 doodles, about 94 MB
python data.py               # sizes, class balance and pixel statistics
```

On the course's test machine the full download took 18 seconds, and `data.py` printed:

```text
10 classes: apple, banana, cat, clock, cloud, fish, house, star, tree, umbrella
  train (90000, 1, 28, 28)  per class: 9,000
  val   (10000, 1, 28, 28)  per class: 1,000
  test  (20000, 1, 28, 28)  per class: 2,000
```

To try other objects, pass any names from the official category list, for example `python download.py --classes pear "hot air balloon"`; the script encodes the space for the URL.<Cite id="quickdraw-repo" /> `--per-class 5000` shrinks the download further.

## Summary

- Quick, Draw! has about 50 million doodles in 345 categories, collected from a 20-second drawing game and released under CC BY 4.0, which requires attribution.
- The 28×28 NumPy bitmaps match MNIST's size and polarity but are centred on the bounding box and fill most of the frame.
- HTTP Range requests download only the header and the first $N$ rows: 9.4 MB per class instead of up to 270 MB.
- `np.load(mmap_mode="r")` reads rows lazily; each class is shuffled and split 9,000 / 1,000 / 2,000.
