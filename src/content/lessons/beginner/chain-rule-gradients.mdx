The **chain rule** is the rule for finding the slope of a function that is built by feeding one function into another: the overall slope is the product of the slopes of the pieces.<Cite id="wiki-chain-rule" /> Together with **partial derivatives**, which handle functions of many inputs, and the **gradient**, which collects those partial derivatives into one list, it is the mathematics behind training every neural network in this course.<Cite id="goodfellow2016-numerical" /> The lesson assumes only the slope rules from [Slopes and derivatives](/course/beginner/derivatives/).

## Functions inside functions

A neural network is a long pipeline of simple steps: multiply, add, apply an activation, measure the error. Each step's output becomes the next step's input. In math this is called a **composition** of functions.<Cite id="d2l-calculus" />

Even a small formula can be a composition. In $y = (3x + 1)^2$ two things happen in order:

1. an inner step computes $u = 3x + 1$;
2. an outer step squares it, $y = u^2$.

To know how $y$ responds to a nudge in $x$, we need to know how much $u$ responds to $x$, and how much $y$ responds to $u$.

<Analogy breaks="Gears turn at a fixed ratio everywhere; in a real function the 'ratio' (the slope) can change from point to point, so it must be measured at the current values.">
Think of three gears in a row. If gear A turns gear B three times as fast, and gear B turns gear C fourteen times as fast, then A turns C 3 × 14 = 42 times as fast. The chain rule says slopes along a chain multiply in the same way.
</Analogy>

## The chain rule, piece by piece

Use $y = (3x + 1)^2$ at the point $x = 2$.<Cite id="3b1b-calculus" />

<MathSteps
  title="Chain rule for y = (3x + 1)² at x = 2"
  legend={[
    { symbol: 'u', meaning: 'the inner value, 3x + 1' },
    { symbol: 'dy/du', meaning: 'slope of the outer step' },
    { symbol: 'du/dx', meaning: 'slope of the inner step' },
  ]}
>
  <Step tex="u = 3 \cdot 2 + 1 = \hl{7}, \quad y = 7^2 = 49" words="Forward: compute the inner value first, then the output." />
  <Step tex="\frac{dy}{du} = 2u = 2 \cdot 7 = \hl{14}" words="Outer slope. The power rule on u², evaluated at the current u = 7." />
  <Step tex="\frac{du}{dx} = \hl{3}" words="Inner slope. 3x + 1 rises 3 for every step in x." />
  <Step tex="\frac{dy}{dx} = 14 \cdot 3 = \hl{42}" words="Multiply the slopes along the chain." />
  <Step tex="\frac{dy}{dx} = \hl{\frac{dy}{du} \cdot \frac{du}{dx}}" words="The general chain rule. Longer chains just add more factors." example="Check: expanding gives y = 9x² + 6x + 1, so y′ = 18x + 6 = 42 at x = 2." />
</MathSteps>

The notation $dy/dx$ (read "dee y by dee x") is Leibniz's way of writing the derivative of $y$ with respect to $x$; it looks like a fraction, which makes the chain rule easy to remember.<Cite id="wiki-chain-rule" />

The same recipe works in Python. Compute forward, then multiply the local slopes, and compare against a <Term slug="finite-difference" /> estimate:

```python
def y(x):
    return (3 * x + 1) ** 2

x = 2.0
u = 3 * x + 1        # forward pass: the inner value
dy_du = 2 * u        # outer derivative, d(u^2)/du
du_dx = 3            # inner derivative, d(3x + 1)/dx
print("chain rule:", dy_du * du_dx)

h = 1e-6
print("numerical: ", round((y(x + h) - y(x)) / h, 3))
```

Both lines print `42.0`.

## A first look at how a weight learns

Here is the chain rule doing real work. A model with one <Term slug="weight" /> $w$ predicts $p = w \cdot x$. With input $x = 2$, target $t = 3$ and current weight $w = 0.5$, the squared-error <Term slug="loss-function">loss</Term> is $L = (p - t)^2$.

<MathSteps
  title="Slope of the loss with respect to a weight"
  legend={[
    { symbol: 'p', meaning: 'prediction, w times x' },
    { symbol: 't', meaning: 'target (correct answer)' },
    { symbol: 'L', meaning: 'loss, (p − t)²' },
  ]}
>
  <Step tex="p = 0.5 \cdot 2 = 1, \quad L = (1 - 3)^2 = \hl{4}" words="Forward pass: prediction, then loss." />
  <Step tex="\frac{dL}{dp} = 2(p - t) = 2(1 - 3) = \hl{-4}" words="How the loss reacts to the prediction. Negative: a bigger prediction lowers the loss." />
  <Step tex="\frac{dp}{dw} = x = \hl{2}" words="How the prediction reacts to the weight." />
  <Step tex="\frac{dL}{dw} = -4 \cdot 2 = \hl{-8}" words="Chain rule. Nudging w up by 0.001 should lower L by about 0.008." example="Check: w = 0.501 gives L = 3.992004, a drop of 0.007996." />
</MathSteps>

Applying this backwards through every step of a large network, reusing each intermediate slope, is the algorithm called **backpropagation**, covered in the intermediate track.<Cite id="cs231n-optim2" /> Libraries such as PyTorch do it automatically ("autograd"), but they compute exactly these products.<Cite id="d2l-autograd" />

### When one value feeds two paths

In a network, one number often feeds several later steps; the input to a layer, for example, is read by every neuron in it. The rule for this case is simple: work out the chain-rule slope along each path separately, then **add** the contributions.<Cite id="cs231n-optim2" />

Take $a = 2x$ and $b = x^2$, both computed from the same $x$, and the output $y = a + b$. At $x = 3$:

- path through $a$: $\frac{dy}{da} \cdot \frac{da}{dx} = 1 \cdot 2 = 2$;
- path through $b$: $\frac{dy}{db} \cdot \frac{db}{dx} = 1 \cdot 2x = 6$;
- total: $2 + 6 = 8$.

Writing $y = 2x + x^2$ directly gives $y' = 2 + 2x = 8$ at $x = 3$, the same answer. This "add up the paths" version is called the multivariable <Term slug="chain-rule" />, and backpropagation relies on it every time a value is reused.<Cite id="d2l-autograd" />

## Partial derivatives: one input at a time

Real models have many inputs and many weights. A <Term slug="partial-derivative" /> is the slope with respect to one input while every other input is held fixed at its current value.<Cite id="khan-multivar" /> It is written with a curly $\partial$ ("partial") instead of $d$.

Take $f(x, y) = x^2 y + y$ at the point $(2, 3)$.

<MathSteps
  title="Partial derivatives of x²y + y at (2, 3)"
  legend={[
    { symbol: '\\partial f / \\partial x', meaning: 'slope in the x direction, y frozen' },
    { symbol: '\\partial f / \\partial y', meaning: 'slope in the y direction, x frozen' },
  ]}
>
  <Step tex="\frac{\partial f}{\partial x}: \; y \text{ is a constant, so } x^2 y \to \hl{2xy}, \; y \to 0" words="Freeze y. Then x²y is just x² times a number, and the lone y is a constant with slope 0." />
  <Step tex="\frac{\partial f}{\partial x}(2, 3) = 2 \cdot 2 \cdot 3 = \hl{12}" words="Put in the current values." />
  <Step tex="\frac{\partial f}{\partial y}: \; x^2 y \to \hl{x^2}, \; y \to 1" words="Now freeze x. x² becomes a constant factor in front of y." />
  <Step tex="\frac{\partial f}{\partial y}(2, 3) = 4 + 1 = \hl{5}" words="Put in x = 2." />
</MathSteps>

So near $(2, 3)$, a small step in $x$ changes $f$ about $12 / 5 = 2.4$ times as much as the same step in $y$.<Cite id="d2l-calculus" />

<Callout type="pitfall">
"A partial derivative ignores the other variables." It does not ignore them, it freezes them. The 12 above depends on $y = 3$; at $y = 10$ it would be 40.
</Callout>

## The gradient points uphill

The <Term slug="gradient" /> is the list (a vector) of all the partial derivatives, written $\nabla f$ ("nabla f" or "grad f"). For the example, $\nabla f(2, 3) = [12, 5]$.<Cite id="goodfellow2016-numerical" />

<MathSteps
  title="From partial derivatives to the gradient"
  legend={[
    { symbol: '\\nabla f', meaning: 'the gradient vector' },
    { symbol: '-\\nabla f', meaning: 'the steepest downhill direction' },
  ]}
>
  <Step tex="\nabla f(2, 3) = \hl{[12, \; 5]}" words="Stack the partial derivatives into one vector, one entry per input." />
  <Step tex="\nabla f(x_1, \dots, x_n) = \left[\hl{\frac{\partial f}{\partial x_1}}, \dots, \frac{\partial f}{\partial x_n}\right]" words="The general form: one partial derivative per input. A network with a million weights has a million entries." />
  <Step tex="-\nabla f(2, 3) = \hl{[-12, \; -5]}" words="Flip the signs to get the direction in which f falls fastest." />
</MathSteps>

Among all directions you could step in, the gradient is the one along which the function increases fastest, and its length says how steep that climb is.<Cite id="khan-multivar" /> The reason uses the <Term slug="dot-product" />: the change for a small step $s$ is roughly $\nabla f \cdot s$, which is largest when $s$ points the same way as $\nabla f$.<Cite id="goodfellow2016-numerical" /> <Term slug="gradient-descent">Gradient descent</Term> steps along $-\nabla f$.

<Analogy breaks="A hiker can see the valley; the gradient only describes the ground under your feet, so the steepest local direction does not always lead to the lowest point.">
Standing on a foggy hillside, you cannot see the valley, but your feet can feel which way the ground tilts most. The gradient is that tilt, and walking the opposite way takes you downhill fastest.
</Analogy>

## Try it: checking a gradient numerically

Nudge one input at a time, holding the others fixed, and you have a partial derivative estimate. This is the standard way to test hand-written gradients:<Cite id="cs231n-optim2" />

```python
import numpy as np

def f(v):
    x, y = v
    return x**2 * y + y

def numerical_gradient(f, v, h=1e-5):
    grad = np.zeros_like(v)
    for i in range(len(v)):
        step = np.zeros_like(v)
        step[i] = h                      # nudge one input, hold the rest
        grad[i] = (f(v + step) - f(v - step)) / (2 * h)
    return grad

print(numerical_gradient(f, np.array([2.0, 3.0])).round(4))
```

It prints `[12.  5.]`, matching the partial derivatives by hand. The formula nudges both forwards and backwards ($v + h$ and $v - h$), which is usually more accurate than a one-sided step.<Cite id="cs231n-optim2" />

## Summary

- The chain rule multiplies slopes along a chain of functions: $\frac{dy}{dx} = \frac{dy}{du} \cdot \frac{du}{dx}$, each evaluated at the forward-pass values.
- A partial derivative is the slope with respect to one input while all other inputs are frozen.
- The gradient $\nabla f$ is the vector of all partial derivatives; it points uphill, so $-\nabla f$ points downhill.
- Backpropagation is the chain rule applied systematically through a network to get the gradient of the loss for every weight.
