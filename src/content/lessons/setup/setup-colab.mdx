**<Term slug="google-colab" />** (Colaboratory) runs Python notebooks in your browser on Google's computers. It is free to use, needs only a Google account, and comes with PyTorch, NumPy and Matplotlib already installed.<Cite id="colab-faq" /> It is the quickest way into the course, and the right one for Intel Macs, Chromebooks and computers where you cannot install software.

## Step 1. Open a new notebook

1. Open [colab.research.google.com](https://colab.research.google.com/).<Cite id="colab" />
2. Click **Sign in** (top right) and log in with a Google account.
3. Click **+ New notebook**. (From inside an open notebook: **File → New notebook**.)

<Screenshot src="/screenshots/setup/colab-new-notebook.png" alt="Google Colab start page with the '+ New notebook' button outlined" caption="colab.research.google.com before signing in. After signing in the same page also lists your recent notebooks." source="https://colab.research.google.com/" taken="2026-11-25" pins={[{ label: 'Click **+ New notebook** (sign in first, top right).' }]} />

A notebook named `Untitled0.ipynb` opens with one empty **code cell**. If you have never used a <Term slug="jupyter-notebook">notebook</Term>, Google's [Welcome to Colab](https://colab.research.google.com/notebooks/intro.ipynb) notebook is a five-minute tour.<Cite id="colab-intro" />

## Step 2. Run your first cell

Click in the cell, type the line below, and press **Shift+Enter** (or click the **▶** button left of the cell):

```python
import torch
print(torch.__version__, torch.cuda.is_available())
```

The first run takes a few seconds while Colab connects you to a machine, called a *runtime*.

**Verify it worked:** under the cell you see a version such as `2.x.x+cu12x False`. `False` means you are on a CPU runtime, which is fine for every project. The exact version is whatever Google currently pre-installs, so it may differ from the local-install lessons.<Cite id="colab-faq" />

## Step 3. Install python-chess

PyTorch, NumPy, Matplotlib, Pillow and tqdm are pre-installed. The chess project also needs the `chess` package, which is not.<Cite id="colab-faq" /> Add a cell with:

```python
!pip install chess
```

The `!` sends the line to the runtime's shell instead of to Python. Packages installed this way last **only for the current session**: run the cell again after every reconnect.

## Step 4 (optional). Switch to a GPU

1. Open the **Runtime** menu.
2. Click **Change runtime type**.
3. Under **Hardware accelerator**, choose a **GPU** (on the free tier usually a **T4 GPU**), then **Save**.

<Figure src="/screenshots/setup/ill-colab-runtime.svg" alt="Illustration of the Colab Runtime menu with Change runtime type highlighted, and the dialog with the T4 GPU hardware accelerator selected" caption="Illustration: (1) Runtime menu, (2) Change runtime type, (3) pick a GPU. Menu labels and GPU names change over time; Colab's FAQ calls these the runtime type and hardware accelerator." credit="Own work (illustration)" license="CC BY 4.0" licenseUrl="https://creativecommons.org/licenses/by/4.0/" sourceUrl="https://research.google.com/colaboratory/faq.html" />

Changing the runtime restarts it, so re-run your cells, including `!pip install chess`. Run the Step 2 cell again: it should now end in `True`.

<Callout type="warning">
Free GPUs are **not guaranteed**: availability and session length vary, and idle sessions are disconnected.<Cite id="colab-faq" /> The course's projects all train on a CPU, so a GPU is a bonus, not a requirement. Switch back to CPU when you do not need it.
</Callout>

## Step 5. Save your work

Files on the runtime vanish when the session ends. Two habits keep your work:

- **Notebooks:** **File → Save a copy in Drive** stores the notebook in your Google Drive (folder *Colab Notebooks*).
- **Data and model files:** mount Drive and write to it:<Cite id="colab-io" />

```python
from google.colab import drive
drive.mount('/content/drive')
# then save to e.g. /content/drive/MyDrive/ai-knowledge/
```

Colab asks for permission the first time. Files saved under `/content/drive/MyDrive/` stay after the session ends.

<Analogy breaks="A hotel room is only yours while you pay; Colab is free, but it can still reclaim the machine whenever it needs to.">
Colab is like a hotel room: fully equipped and ready when you arrive, but the room is cleaned when you leave, so take your belongings (save to Drive) before you check out.
</Analogy>

## Opening the course notebooks in Colab

Colab can open any notebook stored in a public GitHub repository through a URL of the form `colab.research.google.com/github/<user>/<repo>/blob/<branch>/<path>.ipynb`.<Cite id="colab-github" /> Where a project ships a notebook, its lesson shows an **Open in Colab** link built this way. For plain `.py` scripts, upload the file with the folder icon in the left sidebar, or paste its code into a cell.

<Exercise id="colab-limits" />

## Colab or local?

| | Colab | Local install |
|---|---|---|
| Setup time | 2 minutes | about 45 minutes once |
| Works offline | No | Yes |
| GPU | Sometimes, free tier | Only with your own NVIDIA card or Apple silicon |
| Files persist | Only in Drive | Yes |
| Runs on Intel Mac, Chromebook | Yes | No (current PyTorch) |

Many learners start on Colab and install locally later; the lessons work identically.<Cite id="pytorch-get-started" />

## Summary

- [colab.research.google.com](https://colab.research.google.com/) → **Sign in** → **+ New notebook**.
- PyTorch and NumPy are pre-installed; run `!pip install chess` once per session.
- **Runtime → Change runtime type → GPU** is optional; free GPUs are not guaranteed.
- Save notebooks with **File → Save a copy in Drive** and data under `/content/drive/MyDrive/`.
