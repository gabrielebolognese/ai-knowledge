PyTorch handles the neural networks; a handful of other libraries handle arrays, plots, images, progress bars, chess rules and notebooks. A **requirements file** lists them all, so <Term slug="pip" /> can install everything with one command.<Cite id="pip-requirements" /> A short script then checks every piece and prints *"All checks passed."*

## Step 1. Get the course code

The companion code, including `code/requirements.txt` and `code/setup/verify_setup.py`, lives in the course's GitHub repository.

1. Open [github.com/gabrielebolognese/ai-knowledge](https://github.com/gabrielebolognese/ai-knowledge).
2. Click the green **Code** button, then **Download ZIP**.<Cite id="gh-download-zip" />
3. Unzip it and copy the **`code`** folder into your course folder, so you have `C:\dev\ai-knowledge\code\requirements.txt` (macOS/Linux: `~/dev/ai-knowledge/code/requirements.txt`).

Prefer Git? The [troubleshooting lesson](/course/setup/setup-troubleshooting/) shows how to clone the repository instead. No download possible? Create `code\requirements.txt` yourself and paste in the file shown in Step 2.

## Step 2. What gets installed

<Callout type="note">
**Why `chess` and not `python-chess`?** The library's PyPI name is **chess** (version 1.11.2), imported as `import chess`.<Cite id="pypi-chess" /> The name `python-chess` still exists on PyPI, but only as a placeholder release that installs `chess`.<Cite id="pypi-python-chess" />
</Callout>

## Step 3. Install them

Make sure the prompt starts with `(.venv)`, that you are in the course folder, and that PyTorch is installed (lesson 6). Then:

```text
python -m pip install -r code/requirements.txt
```

On Windows `code\requirements.txt` works too. pip downloads each package and its dependencies; this takes one to three minutes. Packages already installed, such as torch, are skipped.<Cite id="pip-requirements" />

**Verify it worked:** the last line starts with `Successfully installed` and lists `chess-1.11.2`, `matplotlib-…`, `jupyterlab-…` and others. No line starts with `ERROR`.

## Step 4. Run the verification script

```text
python code/setup/verify_setup.py
```

The script imports every package, prints its version, creates a small tensor and checks for a GPU:

### Reading each line

- **Python**: should be 3.11 or newer. The script stops with a message if not.
- **MISSING** next to a package: install it into the active environment (the line says how).
- **CUDA GPU : False**: correct for a CPU install. `True` plus your card's name means a working CUDA build.
- **Apple MPS : True** on an Apple-silicon Mac means the Apple GPU is available.
- **venv active : False**: you are using the system Python. Activate `.venv` and run again.

<Analogy breaks="A pre-flight checklist is done by a person; this script checks itself, but only what it was written to check.">
The script is a pre-flight checklist: each line is one instrument, and *"All checks passed."* is clearance for take-off.
</Analogy>
