The course's code runs on **Python** with the **PyTorch** library, so you need somewhere to run it. There are three routes: skip setup because you already have the tools, use **Google Colab** in a browser with nothing to install, or do a **full local install** on your own computer.<Cite id="colab-faq" /><Cite id="pytorch-get-started" /> This lesson helps you pick one in two minutes.

## The three routes

| Route | Pick it if | Time | Next lesson |
|---|---|---|---|
| **Skip setup** | You already have Python 3.11+ with PyTorch, an editor and a virtual environment | 0 min | The course dashboard at [/course/](/course/) |
| **Google Colab** | Intel Mac, Chromebook, school or work PC where you cannot install software, or you want to start right now | 5 min | [No install? Use Google Colab](/course/setup/setup-colab/) |
| **Full local install** | You want everything on your own Windows, macOS or Linux computer | about 45 min | [Open a terminal](/course/setup/setup-terminal/) |

Colab is free, runs in the browser and comes with PyTorch, NumPy and Matplotlib already installed. The trade-offs are that sessions time out and free GPUs are not guaranteed.<Cite id="colab-faq" /> A local install takes longer once but then works offline, keeps your files and has no time limits.

<Callout type="tip">
Not sure? Start with Colab today and do the local install later. Every lesson works with both.
</Callout>

### Check whether you can skip

You can skip the whole track if a terminal command `python --version` (on macOS and Linux, `python3 --version`) prints **3.11 or newer** and `python -c "import torch; print(torch.__version__)"` prints a version number. PyTorch 2.15, the current release, requires Python 3.11 or later.<Cite id="pypi-torch" /> Nothing outside this track lists a setup lesson as a prerequisite, and the certificate never requires it.

## What the local install gives you

The full install sets up five things, always in this order.<Cite id="py-downloads" /><Cite id="vscode-download" />

1. **A <Term slug="terminal" />**: the text window where you type commands. Already on every computer.
2. **Python 3.14**: the language the course uses, from [python.org/downloads](https://www.python.org/downloads/). Versions 3.12 to 3.15 also work.
3. **VS Code**: a free editor for reading and running code, from [code.visualstudio.com/download](https://code.visualstudio.com/download).
4. **A <Term slug="virtual-environment" />** called `.venv`: a private folder of packages that belongs to this course only.<Cite id="py-venv" />
5. **PyTorch and friends**: the neural-network library plus NumPy, Matplotlib, Jupyter and python-chess, installed with <Term slug="pip" />.

<Analogy breaks="A real workshop has one toolbox per room; a computer can have many virtual environments side by side, and creating a new one costs nothing.">
Think of a workshop. The terminal is the room you work in, Python is the power supply, VS Code is the workbench, the virtual environment is a toolbox that belongs to one project, and PyTorch is the set of power tools inside it.
</Analogy>

### The install order at a glance

```text
Terminal → Python 3.14 → VS Code (+ Python and Jupyter extensions)
        → project folder → .venv → activate → upgrade pip
        → PyTorch (CPU) → requirements.txt → verify_setup.py
```

Each step in the next lessons has the same three parts: the **direct link**, the **exact button or command**, and a **"Verify it worked"** check with the output you should see.

## What your computer needs

| | Minimum for the course |
|---|---|
| Windows | Windows 10 or 11, 64-bit |
| macOS | Apple silicon (M1 or newer) on macOS 14 Sonoma or later; Intel Macs use Colab |
| Linux | Any current 64-bit distribution with glibc 2.28 or newer (Ubuntu 22.04+, Debian 12+, Fedora) |
| Disk | About 3 GB free (CPU install) |
| GPU | Not needed. Every project trains on a laptop CPU |

PyTorch 2.15's macOS wheels are built only for Apple silicon on macOS 14 or newer, which is why Intel Macs are sent to Colab.<Cite id="pypi-torch" /> The [PyTorch selector page](https://pytorch.org/get-started/locally/) lists the Linux minimums.<Cite id="pytorch-get-started" />

<Callout type="note">
The course recommends **Python 3.14** because every package it uses publishes ready-made files for it today. Python 3.15 is newer but only a few weeks old. Avoid exactly **3.14.1**, which torchvision refuses to install on.
</Callout>

## Summary

- Three routes: **skip**, **Colab** (zero install) or **local install** (about 45 minutes once).
- The local install is terminal → Python 3.14 → VS Code → `.venv` → PyTorch → libraries → verify.
- No GPU is needed; Intel Macs and locked-down PCs should use Colab.
- The setup track is optional and never required for the certificate.
