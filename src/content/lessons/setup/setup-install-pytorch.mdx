**<Term slug="pytorch" />** is the deep-learning library every project in the course uses. It comes in builds for the CPU, which works on any computer, and for graphics cards via NVIDIA's <Term slug="cuda" />, which can train much faster on an NVIDIA GPU.<Cite id="pytorch-get-started" /> The course default is the **CPU build**: all six projects are sized to train on a laptop CPU.

<Callout type="note">
Activate your environment first (lesson 5). The prompt must start with `(.venv)`, otherwise PyTorch lands in the wrong Python.
</Callout>

## Step 1. Decide: CPU or GPU?

```text
Do you have an NVIDIA graphics card?
├─ No / not sure ──────────────────────────────► CPU
└─ Yes → run  nvidia-smi  → driver version ≥ 580?
          ├─ No → update the driver, or use CPU
          └─ Yes ──────────────────────────────► CUDA 13.2
Apple-silicon Mac ─────────────────────────────► the default macOS build (includes the Apple GPU)
Intel Mac ─────────────────────────────────────► Google Colab
```

- **CUDA builds** need an NVIDIA GPU and an NVIDIA driver new enough for CUDA 13, which means version **580 or later**.<Cite id="cuda-release-notes" /> You do **not** need to install the CUDA Toolkit: the PyTorch packages bundle what they need; only the driver matters. Update it from [nvidia.com/drivers](https://www.nvidia.com/en-us/drivers/).<Cite id="nvidia-drivers" />
- **AMD or Intel graphics on Windows:** use CPU.
- **Download size:** about 120 MB for the CPU build, about 2 GB for a CUDA build.<Cite id="pt-wheel-cpu" />

<Analogy breaks="A van and a truck carry the same cargo; CPU and GPU PyTorch also give the same results, only the speed differs.">
The CPU build is a reliable van that fits in any garage; the CUDA build is a lorry that is much faster on the motorway but only drives if you own the right road, an NVIDIA card.
</Analogy>

## Step 2. Get the command from the selector

Open [pytorch.org/get-started/locally](https://pytorch.org/get-started/locally/) and scroll to the grid of tiles. Click, row by row: **Stable**, **your OS**, **Pip**, **Python**, and the **Compute Platform**. The box **Run this Command** shows the command to copy.<Cite id="pytorch-get-started" />

<Callout type="pitfall">
On **Linux**, plain `pip install torch` downloads the large CUDA build even on a computer without a GPU. Use the CPU command with `--index-url …/whl/cpu` unless you have an NVIDIA card.<Cite id="pytorch-get-started" />
</Callout>

## Step 3. Install it

The selector writes `pip3`. Inside the environment, use the safer `python -m pip` form with the same arguments:

| Your choice | Command |
|---|---|
| **CPU, any OS** (course default) | `python -m pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu` |
| Apple-silicon Mac | `python -m pip install torch torchvision` |
| NVIDIA GPU, Windows or Linux | `python -m pip install torch torchvision --index-url https://download.pytorch.org/whl/cu132` |

The explicit CPU index works on Windows, macOS and Linux, so one command covers everyone.<Cite id="pt-wheel-cpu" /> The download takes a few minutes; the last line reads `Successfully installed … torch-2.15.0 …`.

PyTorch 2.15 needs **64-bit Python 3.11 or newer**,<Cite id="pypi-torch" /> and torchvision excludes exactly Python 3.14.1.<Cite id="pypi-torchvision" /> If pip says *"No matching distribution found for torch"*, check `python --version` first.

## Step 4. Verify it worked

```text
python -c "import torch; print(torch.__version__, torch.cuda.is_available())"
```

| You see | Meaning |
|---|---|
| `2.15.0+cpu False` | CPU build on Windows or Linux. **Correct for the course.** |
| `2.15.0 False` | macOS build (check the Apple GPU below) |
| `2.15.0+cu132 True` | CUDA build that can see your NVIDIA GPU |
| `2.15.0+cu132 False` | CUDA build but no usable GPU: update the driver (`nvidia-smi`) |

The PyTorch page suggests one more check, creating a random tensor:<Cite id="pytorch-get-started" />

```text
python -c "import torch; print(torch.rand(5, 3))"
```

Expected: a 5 × 3 grid of numbers between 0 and 1.

### Apple-silicon Macs: the GPU (MPS)

On M-series Macs, PyTorch can use the Apple GPU through its **MPS** backend:<Cite id="pt-mps" />

```bash
python -c "import torch; print(torch.backends.mps.is_available())"
```

`True` means it is available. The course trains on the CPU by default; a few operations are not yet supported on MPS and may need to run on the CPU instead.<Cite id="pt-mps" />

## Summary

- **CPU** is the course default; choose **CUDA 13.2** only with an NVIDIA GPU and driver ≥ 580.
- The selector at [pytorch.org/get-started/locally](https://pytorch.org/get-started/locally/): Stable → OS → Pip → Python → Compute Platform.
- Install inside `(.venv)` with `python -m pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu`.
- `2.15.0+cpu False` is a correct CPU result; Apple-silicon Macs can check `torch.backends.mps.is_available()`.
