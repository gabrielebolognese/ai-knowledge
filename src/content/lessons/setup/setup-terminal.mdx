A **<Term slug="terminal" />** is a window where you type a command, press **Enter**, and read the answer as text. Every install step in this track, and every "run this script" in the course, happens there.<Cite id="ms-terminal" /> This lesson opens it on your system and runs three harmless commands.

## Open a terminal

### Windows 11

1. Press the **Windows** key.
2. Type `terminal`.
3. Press **Enter**. *Windows Terminal* opens with a **PowerShell** tab.

Alternative: right-click the **Start** button and choose **Terminal**. Windows Terminal is built into Windows 11.<Cite id="ms-terminal" />

### Windows 10

Press **Windows**, type `PowerShell`, press **Enter**. You can also install *Windows Terminal* for free from the Microsoft Store, as described on [Microsoft's install page](https://learn.microsoft.com/en-us/windows/terminal/install).<Cite id="ms-terminal" />

### macOS

1. Press **⌘ Command + Space** to open Spotlight.
2. Type `Terminal`.
3. Press **Return**.

### Linux

On Ubuntu press **Ctrl + Alt + T**, or open **Activities** and type `Terminal`. Other desktops call it *Terminal* or *Console* in the app menu.<Cite id="ubuntu-terminal" />

## Your first three commands

Type each line exactly, then press **Enter**.

**1. Say hello**

```text
echo hello
```

**Verify it worked:** the next line shows `hello`. This proves the terminal reads your commands.

**2. See where you are and what is here**

| | Windows (PowerShell) | macOS / Linux |
|---|---|---|
| List the files here | `dir` (or `ls`) | `ls` |
| Go into a folder | `cd Desktop` | `cd Desktop` |
| Go up one folder | `cd ..` | `cd ..` |
| Show the current folder | `pwd` | `pwd` |

In PowerShell, `dir` and `ls` are both short names for the same command, `Get-ChildItem`, and `cd` is short for `Set-Location`.<Cite id="ms-ps-location" /> On macOS and Linux, `ls` and `cd` are the standard commands.<Cite id="ubuntu-terminal" />

**Verify it worked:** after `cd Desktop`, the prompt ends in `Desktop`. Type `cd ..` to go back.

**3. Ask for Python's version**

```text
python --version
```

On macOS and Linux type `python3 --version` instead. If Python is installed you see something like `Python 3.14.10`. On a new computer you will probably see an error such as *"not recognized"*, or on Windows the Microsoft Store may open.<Cite id="py-using-windows" /> **That is expected**: the next lesson installs Python.

<Analogy breaks="A receptionist can guess what you mean; a shell cannot. One wrong letter and it answers with an error.">
The terminal is like a receptionist who only accepts written requests. You hand over one line, they carry it out and hand back a reply, and the prompt is them saying "next, please".
</Analogy>

## Reading the prompt

The text before the cursor is the **prompt**. It tells you two things: which program is listening, and which folder you are in.

| Prompt | Meaning |
|---|---|
| `PS C:\Users\you>` | Windows PowerShell, in your home folder |
| `you@Mac ~ %` | macOS (zsh), `~` means your home folder |
| `you@host:~$` | Linux (bash) |
| `(.venv) PS C:\dev\ai-knowledge>` | Same shell, with a virtual environment switched on (lesson 5) |
| `>>>` | **Not** the shell: this is Python's own prompt |

### Shell prompt or Python prompt?

Typing `python` (or `python3`) **on its own** starts the <Term slug="python-interpreter">Python interpreter</Term> and changes the prompt to `>>>`.<Cite id="py-tutorial-interpreter" /> There you type Python code, such as `2 + 2`, not shell commands. Leave it with `exit()` and Enter, or with **Ctrl+Z then Enter** on Windows and **Ctrl+D** on macOS and Linux.<Cite id="py-tutorial-interpreter" />

<Callout type="pitfall">
Running `pip install ...` or `python script.py` at the `>>>` prompt gives a `SyntaxError`. Type `exit()` first, then run the command at the shell prompt.
</Callout>

## Terminal habits that save time

- **Copy and paste work.** In Windows Terminal, paste with **Ctrl+V** or a right-click; on macOS, **⌘V**; in most Linux terminals, **Ctrl+Shift+V**.<Cite id="ms-terminal" />
- **Up arrow** recalls the previous command, so you can fix a typo and press Enter again.
- **Tab** completes folder and file names: type `cd Desk` and press Tab.
- **Ctrl+C** stops a running command (for example a training run you want to cancel).
- **Open a new terminal after installing anything.** A terminal reads its list of program folders, the <Term slug="path-variable">PATH</Term>, only when it starts.<Cite id="py-using-windows" />

## Summary

- Windows: **Win → `terminal` → Enter** (PowerShell). macOS: **⌘ Space → `Terminal`**. Linux: **Ctrl+Alt+T**.
- `echo hello`, `cd`, `dir`/`ls` and `python --version` are your first commands.
- `PS C:\...>`, `%` or `$` is the shell; `>>>` is Python. Use `exit()` to go back.
- After installing anything, open a **new** terminal so it sees the new program.
