**Reinforcement learning** (RL) is the branch of machine learning in which an *agent* learns to act by trial and error, guided by rewards, rather than by copying labelled answers.<Cite id="wiki-rl" /> **Self-play** applies it to games: the program plays against copies of itself and learns from the outcomes. Combined with a deep network and tree search, this produced AlphaGo and AlphaZero, the systems that showed a computer could learn Go and chess from scratch at superhuman level.<Cite id="silver2017" /> This lesson is an overview without code, explaining the ideas and why the course's chess engine takes a different, cheaper route.

## The vocabulary of reinforcement learning

RL describes a loop. The **agent** observes the **state** of an **environment**, chooses an **action**, and receives a **reward** and the next state. The agent's decision rule, from states to actions or to probabilities over actions, is its **policy**.<Cite id="spinningup-rl" /> The goal is to maximise the **return**, the total reward collected over time, usually with later rewards *discounted* by a factor $\gamma$ slightly below 1.<Cite id="spinningup-rl" /> A **value function** estimates the return expected from a state when following a given policy.<Cite id="spinningup-rl" />

| RL term | In a chess game |
|---|---|
| Environment | The board and the rules, including the opponent |
| State | The current position |
| Action | A legal move |
| Reward | +1 for a win, 0 for a draw, −1 for a loss, given only at the end |
| Policy | Probabilities for each legal move in a position |
| Value | Expected result from a position |

That delayed reward is the central difficulty, called the *credit assignment problem*: when a long game is won, which moves were responsible?<Cite id="wiki-rl" />

## Samuel's checkers player

The idea of a program improving at a game through <Term slug="reinforcement-learning">trial and error</Term> is old. In 1959 Arthur Samuel of IBM described a checkers program that searched ahead with minimax and adjusted the weights of its scoring function from experience, including games against another version of itself.<Cite id="samuel1959" /> The paper's title used the phrase "machine learning", and Samuel reported that the program learned to play better than its author.<Cite id="samuel1959" />

## AlphaGo and AlphaZero

Go resisted classic search because its branching factor is huge and good evaluation functions were hard to write. DeepMind's AlphaGo (2016) combined three pieces: a **policy network** first trained to predict expert human moves and then improved by self-play, a **value network** that estimated the winner from a position, and **Monte Carlo tree search** (MCTS) that used both.<Cite id="silver2016" /> It defeated the European Go champion Fan Hui by 5 games to 0, the first time a computer program had beaten a human professional player in the full-sized game of Go.<Cite id="silver2016" />

**AlphaZero** (2017) removed the human data. Starting from random play and knowing only the rules, it learned chess, shogi and Go by <Term slug="self-play" /> with one network per game that has two outputs: a policy head (which moves look promising) and a value head (who is winning).<Cite id="silver2017" /> Its training loop has three steps:<Cite id="silver2018" />

1. Play a game against itself, choosing each move with MCTS guided by the current network.
2. Store every position with the search's visit counts per move and the final result.
3. Train the network so its policy matches the visit counts and its value predicts the result, then repeat with the improved network.

<Term slug="monte-carlo-tree-search">MCTS</Term> grows a search tree selectively. At each node it picks the move that maximises an estimate of how good the move is plus a bonus for moves the network likes but the search has rarely tried. AlphaZero uses a variant called PUCT:<Cite id="silver2017" />

The results were striking. The 2017 preprint reports that AlphaZero outperformed Stockfish after about 4 hours of training, while searching about 80 thousand positions per second against Stockfish's 70 million; its self-play ran on 5,000 first-generation TPUs.<Cite id="silver2017" /> In the longer match published in 2018, AlphaZero won 155 games against Stockfish and lost 6, the rest being draws.<Cite id="silver2018" /> **Leela Chess Zero** (Lc0) is an open-source engine inspired by AlphaZero, with a network that provides both a value and a policy and is trained by volunteers' self-play.<Cite id="lczero" />

## Two ways to put a network into a chess engine

| | AlphaZero / Leela | Stockfish with NNUE |
|---|---|---|
| Search | MCTS with PUCT | Alpha-beta with many refinements |
| Network | Large deep residual network, policy and value | Small network, value only, run on the CPU |
| Speed | Tens of thousands of positions per second | Tens of millions per second |
| Training data | Self-play games | Positions scored by engine searches |

Stockfish's NNUE evaluator is designed to be updated incrementally as moves are made and run in integer arithmetic on an ordinary processor, so the search can stay fast.<Cite id="nnue-doc" /> The two families now borrow from each other: Stockfish 18's network was trained on over 100 billion positions of Lc0 evaluation data.<Cite id="sf18" />

## Why the chess project uses supervised learning

AlphaZero-style training must play millions of games, each needing many network evaluations, which requires compute far beyond a laptop.<Cite id="silver2017" /> The course's engine follows the Stockfish route instead. [A training set from the Lichess evaluation database](/course/project-chess/chess-dataset/) collects positions that Stockfish has already scored; [Training the evaluator](/course/project-chess/chess-train-evaluator/) fits a small network to those scores by ordinary supervised regression; and [Plugging the network into search](/course/project-chess/chess-nn-search/) places it at the leaves of the alpha-beta search from [the game-tree lesson](/course/advanced/game-tree-search/). This trains in minutes to hours on a CPU and still teaches the central idea: a learned evaluation inside a search.

## Summary

- RL learns a policy from rewards by trial and error; the return adds up discounted future rewards, and a value function predicts it.
- Self-play makes a game program its own opponent and its own source of training data.
- AlphaZero joins a policy/value network with MCTS (PUCT) and learns from self-play alone; Leela Chess Zero is its open-source descendant.
- Stockfish uses alpha-beta with a small, fast NNUE value network trained on searched positions, the approach the course's chess project follows.
