term: "Reinforcement learning"
short: >-
  Machine learning in which an agent learns a policy by trial and error: it acts in an environment, receives rewards, and adjusts its behaviour to maximise the total reward it collects.

The core terms are agent, environment, state, action, reward, policy (the agent's decision rule), return (the discounted sum of future rewards) and value function (the expected return from a state).
